
# urbio-eco-targets-parallel

<!-- badges: start -->
<!-- badges: end -->

The goal of urbio-eco-targets-parallel is to demonstrate a workflow for using the connectivity analysis with targets.

It runs against urbioconnect at urbio-ecology/urbioconnect@876be8e. Install that, then run the pipeline:

``` r
pak::pak("urbio-ecology/urbioconnect@876be8e")
targets::tar_make()
```
